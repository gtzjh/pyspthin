# pyspthin

`pyspthin` is a Python reimplementation of `spThin` that keeps the original greedy thinning semantics while using a sparse conflict graph instead of a dense `N x N` distance matrix.

## Quick Start

Clone the repository, install the package, and run the example:

```bash
git clone https://github.com/gtzjh/pyspthin.git
cd pyspthin
python -m pip install .
python main.py
```

For development installs, use:

```bash
python -m pip install -e .
```
